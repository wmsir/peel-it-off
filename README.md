# 《捏个痛快！》Pop It Off! — 三端源码（Web H5 + Android APP + 微信小程序）

《捏个痛快！》是《撕个痛快！》姊妹篇解压消除游戏：一笔划过相邻同色果冻气泡一路「噗噗噗」捏爆，破裂气压挤进上下左右邻居并逐波触发连锁爆破；关底将整张泡泡纸捏平后亲手撕开薄膜，开箱领取快递藏品摆满温馨房间，并与《撕个痛快！》共享系列收藏柜！

## ✨ 核心玩法与系统亮点

1. **区别传统消消乐的三重体验**
   - **8 方向划线“捏”消**：相邻（含斜向）≥ 2 个同色气泡即可消除，可沿原路退回取消；音高随五声音阶递增。
   - **气压波纹可控连锁**：每个气泡拥有 **瘪① / 圆② / 鼓③** 三档鼓胀度；实时预览波纹会提前高亮即将被充气的邻居与会自爆的鼓③群。
   - **捏平整张 + 撕开快递**：通关瞬间剩余步数化成“快乐手指”把整张泡泡纸快速捏平，最后滑动撕开泡泡膜揭晓快递。

2. **3 种奖励泡 & 7 种物理障碍**
   - **奖励气泡**：一笔划 `≥ 6` 个终点生 **十字气泵**（整行+整列 +1 气）；单次连锁自爆 `≥ 8` 个末爆点生 **大气球**（3×3 范围内 +2 气并震碎硬化塑料）；一笔划 `≥ 9` 个终点生 **彩虹泡**（接任意色且中途变色）。
   - **障碍机制（前 30 关 6 章逐层解锁）**：**L4 胶带封口**（联动《撕个痛快！》，邻爆翘角 2 次脱落）、**L9 漏气泡**（每步 -1 气，瘪到底变硬塑料片阻断连锁）、**L11 双层泡**、**L14 冰冻泡**（隔绝气压，直划融化）、**L19 硬纸板格**（异形货箱切割）、**L21 钢钉**（每 3 步把邻泡戳瘪）、**L25 小猫爪**（提前 1 步 `🐾` 预警拍瘪）。

3. **三大模式 & 长期留存**
   - **📦 闯关拆箱**：前 30 关 6 间主题快递房 + 第 31 关起 AI 校验无限挑战 + 4 周双十一限定赛季 10 关；连输 3 次自动免费 +3 步。
   - **🫧 无尽捏捏（L3 解锁）**：无限步数、**永久 0 广告、无任务压力**，可选 **钢琴音 / 雨声 / 白噪音** 三套解压声景。
   - **🏆 每日一捏（L8 解锁）**：按日期生成全服同图，15 步内挑战单次最大连锁与百分位排名。
   - **🏠 快递房间 & 共享收藏柜 + 7 日解压日历 + 5 套泡泡纸皮肤**。

## 📁 目录结构

```text
peel-it-off/
├── web/                        # Web H5 独立源 & Android WebViewAssets 单一源（PopCore + PopAudio + PopGameApp）
├── android-app/                # Android Gradle / Kotlin WebViewAssetLoader 工程
├── wechat-miniprogram/         # 微信小程序原生源码（Canvas 2D + WxPopAudio + WxAdManager 流量主接入）
├── scripts/
│   ├── sync-assets.js          # 同步 web/ -> android-app/assets/www & web/levels.js -> wechat-miniprogram/utils/levels.js
│   └── verify-all.js           # 全端语法/结构校验 + 物理单测 + 30 关×200 局（6,250 局）AI 校准门禁
└── .github/workflows/
    └── build-release.yml       # 自动编译 Debug/Release APK、打包微信 zip 并发布 Release
```

## 🛠️ 本地运行、校验与发版

1. **PC / 手机浏览器试玩**：直接用浏览器打开 [web/index.html](web/index.html) 即可体验全部关卡与桌面调试面板。
2. **微信小程序导入**：使用 **微信开发者工具** 打开 `wechat-miniprogram/` 目录；如需接真实流量主广告，在 `wechat-miniprogram/utils/ad.js` 填入 `rewardedAdUnitId`。
3. **全量校验（含 6,250 局 AI 校准模拟）**：
   ```bash
   npm test
   ```
4. **GitHub Actions 自动构建 APK & Release**：推送 `v*` 标签后自动输出：
   - `pop-it-off-release.apk`
   - `pop-it-off-debug.apk`
   - `pop-it-off-wechat-miniprogram.zip`
